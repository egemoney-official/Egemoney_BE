# 퀴즈 품질 블라인드 평가 루브릭

상위 2개 청킹 전략으로 생성한 퀴즈를 전략명이 보이지 않게 섞은 뒤, 팀원이 각 항목을 1~5점으로 평가한다.

| 항목 | 1점 | 3점 | 5점 |
|---|---|---|---|
| 사실 정확성 | 근거와 다르거나 오답 가능성이 큼 | 대체로 맞지만 표현이 모호함 | 검색 컨텍스트에 정확히 근거함 |
| 난이도 적합성 | 요청 난이도와 크게 어긋남 | 일부 문항만 난이도가 맞음 | 요청 난이도에 일관되게 맞음 |
| 해설 품질 | 해설이 없거나 정답 근거가 부족함 | 핵심 근거는 있으나 설명이 짧거나 장황함 | 2~3문장으로 정답 근거가 명확함 |
| 중복성 | 같은 개념이 반복됨 | 일부 유사 문항이 있음 | 문항별 핵심 개념이 잘 분산됨 |
| 학습 유용성 | 금융문맹 해소에 도움이 적음 | 개념 확인에는 도움이 됨 | 생활 금융 의사결정에 바로 연결됨 |

평가자는 문항별 점수와 짧은 코멘트를 남긴다. 전략별 최종 점수는 항목 평균의 전체 문항 평균으로 계산한다.
